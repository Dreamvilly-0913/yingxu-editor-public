# 映序剪辑 0.5.0 · 蒙版、缓动与工程恢复

日期：2026-10-15。文中项目路径均相对于仓库根目录。本轮继续补齐桌面编辑流程；原测试环境中的 0.4.0 交付目录保持不变，未随本公开源码快照发布。

## 新增行为

- 矩形／椭圆蒙版：中心、宽高、旋转、羽化、反转；跟随片段裁剪后的源画面变换，保留图片原透明通道。预览缓存蒙版 alpha，再参与同一个 sRGB 画布合成；导出用相同的几何和羽化定义。
- 关键帧：线性、缓入、缓出、缓入缓出、保持。曲线控制进入目标关键帧的区间。使用独立的二次曲线预设；保持模式在区间末端跳变。分割、修剪和插入关键帧保存曲线子区间，避免重新从完整曲线起步造成跳动。恒定变速同时重定时关键帧。
- 自动恢复：编辑后约一秒暂存；串行写入、临时文件原子替换；正常保存清除当前暂存，尚未处理的上次恢复记录保留到明确恢复或忽略。同一用户数据目录单实例运行，连续保存与切换工程都有并发保护。重启通过明确的恢复入口重新读取原素材，保留编辑参数；不覆盖原工程。缺失素材保留恢复记录，损坏记录可忽略。
- UTF-8 SRT 导出：按开始时间排序，输出毫秒时间，保留中文、多行文本与表情。SRT 使用空行分隔条目，同一条字幕内有空白段落时会提示删除空行后导出，工程文字保持不变。保留自动字幕、字幕编辑和 SRT 导入。
- 新增随包演示工程“蒙版与缓动演示”，使用本项目既有独立素材。

## 对原软件的证据范围

REA 本轮检查了本机安装文件。剪映启动器在启动后自动切换到 11.6.0.14552；新旧二进制分别记录版本与哈希，不复用旧地址。本轮原 GUI 未能安全取得前台，未完成新蒙版工程操作，因此不能宣称与原 GUI 的蒙版结果逐像素一致。

当前原程序资源和局部原生分析能证实蒙版参数字段、矩形／椭圆分支及部分 Bézier 曲线计算。它们不证明所有主时间线分支都采用该实现。映序的归一化坐标、平滑羽化定义和二次缓动预设是独立设计，不冒称剪映原预设的完整恢复。上一版四组原 GUI 色彩对照仍作为历史证据；本轮的重点是新功能及既有 SDR 管线回归。

## 验收记录

最终以 `outputs/final-acceptance-v0.5.0.json` 及其引用报告的实际状态为准。源版模型／FFmpeg测试、实际交付程序的蒙版与缓动 UI 测试、跨进程恢复和 SRT 文件测试、既有多轨／自动字幕／色彩回归分别留存，不能将单元测试当作原软件整机等价。

| 原声、媒体 Range/HEAD、取消与临时文件清理 | 6/6 |
| 反复打开、旧画面回调和跳帧 | 20 次 + 4 组 Range/HEAD |
| 随包三个演示工程 | 12/12；新演示三个时刻实拍 |
| 既有 SDR 色彩回归 | 9 场景、11 帧；同显示域预览与成片最大差 3/255，最终画布与文件解码最大差 4/255 |

新蒙版组合场景使用带不同透明度的 PNG，叠加旋转、羽化、裁剪、镜像与缓动。六个真实 PTS 对齐帧使用 4px 网格采样，预览／成片平均通道差 **1.140–1.216/255**，最大 **14/255**；此值包含边缘采样与编码误差，不能和纯色块的 4/255 混为同一指标。

独立模型／导出测试覆盖八类蒙版、五种缓动、分割和极窄曲线区间。蒙版 2,592 个采样最大误差 4.943/255；缓动 35 帧最大误差 0.984/255；分割前后 100 帧中心亮度差为 0；动画几何中心偏差最大 0.618px。

帧缓存增加内容版本，成功重绘后让下游 RGB 缓存失效，alpha 缓存仍复用。旧版与新版的八次实际跳转都通过，**此项属于缓存健壮性优化，没有将假设竞态描述成已复现故障**。原逆向组件的 14 组 shader／1,515 组 JS 实验另见证据目录，不能计作原 GUI 蒙版等价测试。

实际演示成片为 1280×720、7.4 秒，包含声音和明确的 SDR 标签，包内 `演示成片/蒙版与缓动演示.mp4` 可直接播放。该演示在本轮并发验收环境中导出约 5 分 47 秒；这不是隔离的性能基准，但说明**高分辨率蒙版与动画导出仍有明显优化空间**。本版未将功能正确性验收当成实时性能达标。

## 边界

本版仍不包含曲线变速、任意 Bézier 控制柄编辑、蒙版参数动画／扩张／圆角、复杂特效、模板、降噪及其它云端 AI。受支持的 SDR601／709 与受测 sRGB 图片沿用 0.4 管线；HDR、BT.2020、任意图片 ICC／广色域未完成。预览缩放、蒙版边缘采样、65³ LUT、H.264 4:2:0 和字体栅格化仍可能产生有限差异。没有将此版本表述为剪映全功能复刻或跨机器完整验证。
