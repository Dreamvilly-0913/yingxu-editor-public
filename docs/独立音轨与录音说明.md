# 独立音轨、声音处理与录音

“声音与音轨”工作台支持最多 8 条独立音频轨。每条轨道可命名、设置 0–200% 增益、静音、独听和锁定；允许多个轨道同时独听。存在独听轨时，其它音轨和视频原声静音，静音优先于独听。轨道锁定会保护片段编辑，空轨可以移除。片段可在未锁定的音轨之间移动，均通过工程撤销／重做处理。

选择含原声的视频后可“分离视频原声”。程序把完整源音频解码为单独的持久 WAV 素材，原视频随即静音，新音频片段保留源区间、曲线变速、音量、淡入淡出与声音处理。独立声音不再跟随原视频的转场，需使用音频淡入淡出调整。原文件保持不变，分离操作可以一次撤销。

时间线波形以原素材双声道采样峰值绘制，较亮部分表示 RMS，并依据片段源时间映射显示修剪和曲线变速对应的区间。工作台的采样峰值与 RMS 使用 dBFS，读数来自原素材，不包含轨道增益、声音处理和混音，也不表示 LUFS 或 true-peak 测量。反相左右声道分别统计能量，不先相加而互相抵消。

降噪采用 FFmpeg 频谱降噪，响度归一采用动态 EBU R128 处理，默认目标 −16 LUFS、可设 −24 至 −9 LUFS，归一处理的真峰值目标为 −1.5 dBTP；混音后的共同限制器再控制输出峰值。首次播放含新音轨或声音处理的工程时，会生成 48 kHz 立体声统一试听 WAV；参数更改后重新准备。预览与导出使用相同处理、曲线变速、包络、转场和轨道混音。本轮逐字节一致性针对处理后的 PCM，不把有损 AAC 成片描述为逐字节无损。

“录音”按钮打开本地录音工作台，只有点击“开始录音”才请求麦克风。可选择未锁定的目标音轨，录音从开始时的播放头加入，录音期间暂停工程播放。可查看实际采样电平、停止并加入音轨或取消。每次最长 5 分钟、最多 100 MiB；停止后将流式录音转换为有明确时长的持久 48 kHz 双声道 PCM WAV，再加入工程。超过时长的内容明确拒绝，不截短后当作完整录音。

录音停止、取消或页面关闭时释放采集轨道。录音设备驱动可能自带处理，界面不承诺无处理的原始 PCM。后台只允许编辑器自己主框架的音频设备访问，不授予摄像头或其它框架的采集权限。

本轮录音验收使用 WebAudio 已知 440 Hz 合成流，实际经过 MediaRecorder、主进程转换和工程导入，检查频率、RMS、目标音轨、撤销、取消与资源释放；另用 Chromium 假音频设备验证真实权限回调，未采集用户环境音。详细结果以 `outputs/phase10-audio-ui-source/acceptance.json`、`outputs/phase10-recording-source/acceptance.json` 及打包版对应报告为准。
