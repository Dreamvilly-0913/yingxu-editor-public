# 映序剪辑 · 继续项目

项目目录为本仓库根目录，克隆后默认为 `yingxu-editor-public/`。当前版本 **0.8.0**，独立的 Windows 桌面视频编辑器。

公开源码快照：[Dreamvilly-0913/yingxu-editor-public](https://github.com/Dreamvilly-0913/yingxu-editor-public)。此展示副本采用独立的初始提交，不承接旧私有仓库的提交链，也不附带 Release、程序二进制或模型。先按 [项目说明与从源码启动](README.md) 安装依赖并启动。下文的版本报告保留原测试条件；“包内”指本地构建后的独立程序目录，`outputs/` 中的构建物与报告需在本地生成。

完成本地打包后，可运行 `outputs/映序剪辑-0.8.0-win-x64/映序剪辑.exe`，或双击项目根目录 `启动映序剪辑.cmd`。独立程序目录包含 Electron、FFmpeg、FFprobe、本地 Whisper 语音模型和 ONNX/U2NetP 前景提取运行时，请保留整个目录一起移动。若本机仍在运行旧版，请先保存并关闭，再启动新版；正常使用的多个版本共用用户数据目录。

## 0.8 新增与接续

本轮新增最多 8 条独立音轨与波形、静音／独听／锁定、原声分离、降噪与响度处理、录音；试听与导出共用混音。新增可重叠的独立文字、逐条字幕完整样式、批量样式及批量校对。专业调色支持 Bézier RGB／独立 Y 色调曲线、色轮、分区／六维 HSL 和本地 Cube LUT 导入；视觉处理支持色度抠像、去溢色、12 种透明混合、蒙版动画／扩张／圆角。Bézier 控制柄用于色调曲线，速度曲线仍使用原有速度点和线段。

“运动补帧”“视频防抖”“HDR转SDR”“本地AI抠像”生成独立新素材；AI视频是逐帧显著前景分割，不是对象跟踪。导出新增质量／码率、硬件实测探测与软件回退、区间和48kHz立体声WAV；预览可选原尺寸／1080／720／540，缓存预算清理保留正在引用的文件。

详见 [项目说明与从源码启动](README.md)、[本轮验收](docs/0.8.0-音频文字视觉与本地处理验收.md)。新功能示例为 `assets/demo/音频文字与视觉工作台演示.yxproj`，点击“打开”选择它。正式包的新成片为 `演示成片/音频文字与视觉工作台演示.mp4`，源码项目对应 `outputs/音频文字与视觉工作台演示-v0.8.0.mp4`；最终文件存在与哈希以交付清单为准。已具备持久编组／解组和素材库源入出点；多来源音轨的编组横移保留原轨，移轨请按单轨选择。新版本工程请用 0.8 继续编辑。

边界：本轮不是剪映全部功能或算法等价。逐字富文本／逐词高亮、速度Bezier手柄、原生HDR工作流、对象时序跟踪与云端AI等尚未完成；色彩／字体编码边缘、长片和跨机器质量仍有测试范围限制。

## 使用

导入本地视频、图片与音频，双击素材加入时间线。主轨默认自动衔接，可关闭“主轨磁吸”改为自由时间线，保留空隙；可添加最多 8 条独立视频叠层；在右侧编辑裁剪、镜像、位置、缩放、旋转、透明度和调色。主轨转场支持交叉溶解与淡黑，位置等动画支持线性、缓入、缓出、缓入缓出和保持关键帧；选择某个关键帧的曲线，会控制进入它的动画区间。缓动曲线是本软件的独立二次曲线预设。

0.7 的时间线支持直接拖动片段、拖动首尾手柄修剪。Ctrl／Shift 点击可多选，空白处拖动可框选；多选后可一起移动、删除、复制与粘贴。Ctrl+C 保存复制当时的快照，Ctrl+V 从当前播放头粘贴，保留片段相对位置并生成新 ID。点击“边缘吸附”可开关对齐，拖动时按住 Alt 临时关闭吸附。一个拖动动作对应一次撤销；Esc 取消拖动。自由主轨的空白区域导出为黑画面，未放置音频处保持静音。

“主轨磁吸”和“边缘吸附”分别控制时间线排列和拖动对齐。自由主轨不允许非转场重叠；混合选择主轨与音频／字幕一起移动时，请先关闭主轨磁吸。自由主轨保留并播放已有转场，调整转场需先开启磁吸。文字多选支持批量样式；视频／音频属性仍按单个片段编辑，多选暂不支持批量分割，分割前请只选一个片段。

矩形与椭圆蒙版可调整中心、宽高、旋转、羽化和反转，与裁剪、镜像、调色、位置动画叠加使用。蒙版坐标相对裁剪后的素材，跟随片段变换。

时间线支持分割、排序、删除、0.25–4 倍恒定速度与曲线变速，以及撤销／重做。曲线可选渐快、渐慢、中段慢放等独立预设，也可拖动／输入最多 32 个速度点；横轴为源素材进度，片长根据曲线自动计算。图形变速与原声音轨共用时间映射，输出声音采用带上下文的保音调时间伸缩。分割、修剪会保留对应动画轨迹和声音时间映射；拖动手柄向外延伸时，新扩展部分使用边界速度、姿态与音量，保留部分不变。已裁掉的原曲线可通过撤销恢复，重新延伸不会自动找回被裁掉的内部变化；更换速度方式时，关键帧和音量包络按新片长同比重定时。已有字幕使用时间线绝对时间，改变速度后可重新识别或调整字幕。音频可独立设置起点、音量和淡入淡出；分割会保留原有音量包络。视频画面使用统一的预览代理，声音仍从原文件同步播放，不重复压缩代理音轨。

高级调色新增曝光、色温、色调、高光、阴影、白色／黑色色阶，主曲线与 RGB 分通道控制点，以及八个颜色范围的 HSL 调整。高级调色使用独立 SDR 算法，叠加在已有基础调色之后，预览和导出共用参数。

自动字幕使用本地 Whisper 多语言模型；从源码运行时需先按 [项目说明](README.md) 安装，安装后识别无需联网。识别后可校对并写入可编辑字幕，也支持手动字幕与 UTF-8 SRT 导入／导出。识别与导出均可取消。逐条字幕和独立文字可分别设置字体、字号、颜色、对齐、位置、字距、行高、背景、描边、阴影与变换；支持原子批量校对、字面查找替换和整体平移。SRT 只包含字幕文本与时间，不保存样式或独立文字，完整信息保存在 `.yxproj`。

导出为 H.264 / AAC MP4，可设置画布和帧率。保存 `.yxproj` 后可继续编辑；工程记录原素材相对路径，不把预览缓存打包进工程。0.8 可打开此前的旧工程，旧工程默认保持主轨磁吸；包含本轮新字段的工程请使用 0.8 继续编辑。旧版归一化调色强度保持不变，但界面数值按实测剪映的 −50 至 50 量程显示（旧界面 20 对应新版 10）。

素材丢失时仍可打开工程，时间线保留离线占位，显示原路径与原因。在“工程工具”里可单个重新链接，也可选择文件夹批量匹配原文件名；重名候选不会自动猜选。新文件须满足素材类型和片段所需源时长。替换只更新素材引用，片段修剪、变速、蒙版、调色和关键帧保持。重新链接支持撤销；有被使用的离线素材时，先补齐再导出或识别字幕。没有被使用的离线素材不阻止导出。

“工程工具”提供“另存为”和“归档工程”。另存为成功后切换当前保存位置；归档在所选目录中新建独立文件夹，复制全部素材，写入相对路径工程与素材 SHA-256 清单，保持原工程、原素材和当前保存位置。归档前需补齐全部离线素材，含尚未加入时间线的素材；重名文件使用独立路径保存，不覆盖旧文件。归档不是把剪映私有草稿转换为本软件工程。

编辑后约一秒自动暂存恢复副本。再次启动出现恢复提示时，可恢复或忽略；恢复会重新准备原素材，并作为未保存工程打开，随后请手动保存。自动暂存在应用数据目录，不覆盖原 `.yxproj`。缺失素材时可恢复为离线占位，并在之后重新链接；损坏记录可明确忽略。正常保存或切换工程会清除当前工程的暂存；尚未处理的上次恢复记录会保留，直到明确恢复或忽略。回到已保存状态时也会清理过时的当前暂存。同一用户数据目录只允许一个实例运行，避免恢复文件互相覆盖。

快捷键：空格播放／暂停，S 分割，Delete 删除，Ctrl+A 全选时间线，Ctrl+C 复制，Ctrl+V 粘贴，Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，左右方向键逐帧定位。素材栏支持按名称搜索。

包内 `resources/app/assets/demo/`（源码项目中为 `assets/demo/`）共六个工程：“多轨与动画演示”“调色与声音演示”“蒙版与缓动演示”“曲线变速与高级调色演示”“自由时间线与素材管理演示”和本轮新增的“音频文字与视觉工作台演示”。点击“打开”选择 `.yxproj` 查看；工具栏“演示”仍为内置基础示例。包内 `演示成片/音频文字与视觉工作台演示.mp4` 为 0.8 新示例，旧的自由时间线成片也保留。各轮报告中的性能与色彩数据只适用于注明的版本与测试条件。

## 0.4 色彩处理

依据剪映原程序普通 SDR 视频的实际行为，采用**SDR 显示兼容模式**：按源矩阵与范围解释 YUV，保留编码 RGB 的显示亮度，再统一到预览和导出工作空间。它不宣称是按照所有源标签进行的严格色度管理。

工作视频与成片均显式写入 BT.709 矩阵／原色、sRGB 传递函数、全范围标签，并验证输出。未调色和调色画面使用同一 Canvas 路径，多轨先在同一个 sRGB 画布合成；保留系统显示器 ICC。剪映本身默认导出有限范围 BT.709，二者编码标签策略不同，比较时区分文件 RGB 与显示器截图。

首次导入视频会按当前预览设置准备画面缓存，默认原始尺寸，可查看进度或取消；“预览与缓存”可改为 1080／720／540 高度代理，再次使用可复用缓存，原素材不改动。源文件或色彩策略变化会使缓存失效。缺失标签的素材会在属性面板列明默认解释，无法凭缺失信息恢复拍摄时的真实色彩意图。

此前报告：[0.3.0 逆向复现与比较](docs/0.3.0-逆向复现与比较.md)。0.3.0 的 31 项测试包括原有 24 项、6 项新增模型／媒体测试及 1 项媒体协议测试。历史报告中“未运行原软件 GUI”和“跨路径色差最大 56”只描述当时状态，不是 0.4.0 的结论。

当前功能边界：不支持原生 HDR／广色域编辑与杜比视界、任意图片 ICC 色度管理；PQ／HLG 视频可先用专用入口转换为 SDR。已支持独立音频轨、波形、字幕样式、蒙版动画／扩张／圆角、色轮、LUT和可选声音降噪。仍未完成逐字富文本、逐词高亮、任意 Bézier 速度控制柄、专业示波器、复杂特效、模板及云端 AI，也不宣称兼容剪映私有草稿。原软件整机比较覆盖报告列出的合成短片和调色条件，未完成全部功能、长片或其它机器的验证。

预览会按显示尺寸缩放，导出使用 65³ 调色 LUT 与 H.264 4:2:0 编码；插值、字体栅格化、压缩、色度边缘及显示器 ICC 不保证逐像素完全相同。多轨高分辨率导出和首次全尺寸代理会增加时间与磁盘占用；0.6 历史受测图片和运动视频蒙版导出约提速 5.5–6.3 倍；0.8 延续该合成路径并增加本轮功能，但本轮未重跑端到端高分辨率性能基准；4K 多轨仍使用 CPU 合成，长片和更多机器的性能尚未全面验证。0.8 大尺寸图片动态蒙版的组合示例出现600秒导出超时，仍为性能限制；交付720p示例使用320×180叠层素材，详见本轮验收。
