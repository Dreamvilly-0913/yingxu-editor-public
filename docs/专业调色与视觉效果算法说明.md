# 专业调色与视觉效果实现说明

本轮使用独立实现的 SDR 算法，不复制剪映的着色器、LUT、素材或商业资源；功能名称相近不表示算法与剪映相同。

## 调色链

先执行此前版本的基础调色和高级调色，再执行可选 `advancedColor.professional`。旧工程没有该字段时保留此前算法和数据形状。专业链依次为 Lift / Gamma / Gain / Offset、分区色偏、Bezier RGB 与独立 Y 曲线、六维 HSL 选区、导入的 Cube LUT。

Bezier 曲线最多 16 个锚点，控制柄使用绝对归一化坐标，横坐标保持单调，纵坐标限制在 SDR 0–1。独立 Y 使用 Rec.709 系数 0.2126 / 0.7152 / 0.0722 计算亮度，以等量 RGB 偏移映射亮度；没有通道溢出时保留色差。

四个色轮使用独立 RGB 向量，范围 −1 至 1。Lift 为 `x + lift * 0.25 * (1-x)`；Offset 增加 `offset * 0.25`；Gamma 指数为 `2^(-gamma)`；Gain 乘 `2^gain`。分区色偏以平滑阴影和高光权重混合，中间调取剩余权重，分区范围不可交叉。

六维 HSL 指色相、饱和度、明度及它们各自的作用范围，三个选区相乘并带柔化。它与原有八个颜色段的 HSL 独立，可叠加。

支持分别导入 1D Cube（2–4096）或 3D Cube（2–65³），带输入域和强度；不接受一个文件中的 1D+3D 组合。LUT 数据嵌入 `.yxproj`，工程转移后无需再次寻找原 Cube。导入入口限制文件大小为 24 MiB。

GPU 专业链和导出都采用 65³ 查找表与四面体插值；纹理只在专业调色参数变化时重建。复杂 HSL 选区边界的直接数学值与 65³ 近似并非完全相同：受测随机画面最大 14/255、均差约 0.228/255；同一画面的 GPU 与实际 FFmpeg 65³ 输出最大差 1/255。报告分别记录这两种误差，不把它们混为一谈。最终 H.264 4:2:0、缩放与显示 ICC 还有各自的差异。

## 抠像与混合

`visualEffects.chromaKey` 在原始 RGB 上计算抠像、去溢色，再进入调色。颜色距离为归一化 RGB 欧氏距离；阈值以内移除，过渡宽度线性改变覆盖率。保留原素材透明度，并乘以抠像覆盖率。去溢色仅压低被移除或部分移除边缘的优势颜色通道；中性抠像色不产生彩色去溢。

边缘平滑为 0–4 的整数源像素，以 3×3、1/2/1 权重计算覆盖率，不模糊主体 RGB。边界采样夹到素材范围内。它是普通色度抠像，不是人物 AI 分割。

混合模式支持正常、正片叠底、滤色、叠加、变暗、变亮、差值、排除、强光、柔光、颜色减淡、颜色加深。共享计算采用 straight RGBA 输入，先换算为预乘能量合成，最后除以输出 alpha；透明度只应用一次。预览使用相同含义的 Canvas 混合模式。

## 蒙版

保留矩形和椭圆蒙版的旧覆盖率。新增 `expansion` 按裁剪后短边增加或缩小签名距离，`roundness` 为矩形最大内接圆角的比例；椭圆不需要圆角。

`maskAnimation.keyframes` 时间相对片段起点，每帧保存完整的中心、大小、旋转、羽化、扩张与圆角，支持线性、缓入、缓出、缓入缓出和保持。切片保存原缓动参数窗口，避免修剪后重新开始缓动；延伸持有边界值。

静态高分辨率蒙版按尺寸和参数缓存覆盖率，默认最多 64 MiB；命中时复用已有 Buffer，动画才按变化的参数生成。受测 4K 静态覆盖率占用 8,294,400 字节。

- `scripts/phase10-visual-signals.cjs`：真实 Electron GPU、FFmpeg 抠像/动画蒙版与 65³ 调色信号比较；加 `--packaged` 检查独立程序内代码。
- `scripts/phase10-visual-controls.cjs`：真实鼠标键盘操作控制柄、色轮、LUT、抠像、混合、关键帧以及取消/工程切换保护。
